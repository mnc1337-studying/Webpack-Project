# Webpack: базова версія

Невелика сторінка з фактами про космос. Конфіг Webpack (`webpack.config.js`) об'єднує всі вихідні файли в одну збірку.

## Запуск

Потрібен Node.js версії 18+.

    npm install
    npm run dev      # сервер розробки на http://localhost:3000
    npm run build    # продакшн-збірка в папку dist/

## Що налаштовано

- **Хеші в іменах файлів.** Стилі, скрипти, шрифти й картинки отримують хеш від вмісту, тому браузер не тримає застарілу версію в кеші. У dev-режимі для JS хеші вимкнені, щоб не заважати hot reload.
- **Шрифти.** Шрифт Courier New підключено локально через `@font-face` (формати woff2 і woff), Webpack копіює їх у `dist/assets/fonts`.
- **Зображення.** Фонова картинка підтягується з CSS і теж потрапляє в збірку з хешем.
- **CSS.** У dev стилі вставляє `style-loader`, у production вони виносяться в окремий мінімізований файл.
- **Бібліотеки.** З `lodash-es` імпортується лише `debounce`, а все з `node_modules` лежить в окремому файлі `vendors`.
