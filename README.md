# Webpack-Project

Навчальний проєкт із Webpack, розділений на дві частини.

- [`basic/`](./basic): базова збірка (хешування, шрифти, картинки, CSS, бібліотеки)
- [`advanced/`](./advanced): розширена версія з додатковими можливостями збірки (TypeScript, Sass/LESS, Babel, ESLint, Bundle Analyzer)

Кожна директорія - це окремий проєкт зі своїм `package.json`, тож запускати проект треба з неї:

    cd basic        # або cd advanced
    npm install
    npm run dev
